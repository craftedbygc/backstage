# Extensions

Extensions enhance Studio during development. Runtime animation still flows through `@unseenco/theatre-core`.

| Extension | Package | Guide |
| --- | --- | --- |
| Three.js | `@unseenco/theatre-threejs` + `/extension` | [Three.js](./threejs.md) |

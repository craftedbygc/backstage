# Getting started

Choose a guide based on how you build your page:

| Guide | Best for |
| --- | --- |
| [With THREE.js](./with-three-js.md) | Bundled apps using Three.js directly |
| [With HTML / SVG](./with-html.md) | Static HTML, no bundler |
| [With React Three Fiber](./with-react-three-fiber.md) | R3F apps (manual wiring in this fork) |

All guides use **`@unseenco/backstage`** for playback and **`@unseenco/backstage/studio`** during development. Strip Studio from production bundles when you ship.

After a tutorial, read [Concepts](../concepts.md) and the [manual](../manual/index.md).

# Keyboard & mouse controls

### Studio-wide

| Action | Input |
| --- | --- |
| Play / Pause | `Space` |
| Hide / Show Studio | `Alt`/`Option` + `\` |
| Undo | `Ctrl`/`Cmd` + `Z` |
| Redo | `Ctrl`/`Cmd` + `Shift` + `Z` |

### Focus range

| Action | Input |
| --- | --- |
| Create focus range | `Shift` + drag in the sequencer header |

### Details Panel

| Action | Input |
| --- | --- |
| Slow scrub on numbers | `Alt`/`Option` + drag on a number prop |

### Dope sheet

| Action | Input |
| --- | --- |
| Select keyframes | `Shift` + drag in the Sequence Editor |
| Context menu | Right click |
| Place marker at playhead | Right click the playhead |
| Zoom | `Ctrl`/`Control` + scroll (or pinch) |
| Pan horizontally | `Shift` + scroll |

### Keyframe curve popover

| Action | Input |
| --- | --- |
| Navigate presets | Arrow keys |
| Cancel | `Escape` |
| Apply | `Enter` |

### Color picker

| Action | Input |
| --- | --- |
| Move pointer | Arrow keys |

Legacy docs included demo videos for each action; screen recordings can be added under `docs/public/` later.
